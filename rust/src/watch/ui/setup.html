Rules

A rule watches class counts per processed frame. Join conditions with and / or; prefix lua: for a sandboxed Lua expression.

New rule


          

          
Hold counts consecutive processed frames, not seconds. Counts measure detections in a frame. The line follows the class/When/Number fields until you edit it by hand.

          
Rule and Lua syntax
            
seen("person") true when the class is detected.

            
count("cell phone") >= 4 detections of a class in one frame. Operators: > < >= <= ==.

            
ratio("cell phone", "person") >= 0.2 relative proportion of two classes.

            
lua: count("cell phone") >= 4 and count("person") > 0 a sandboxed Lua boolean; no files, no network. A runtime error fails closed (no alert).

            
Visible phones and proximity do not prove a person is holding or using a phone.
