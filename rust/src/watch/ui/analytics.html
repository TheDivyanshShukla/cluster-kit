Add a phone camera

No camera connected? A phone on the same Wi-Fi can be a live camera. Any app that publishes an RTSP or HTTP MJPEG stream will do.

  1. Android: start an app that serves video over the network (for example an IP-webcam style app). Typical addresses are http://<phone-ip>:8080/video or rtsp://<phone-ip>:8554/...; the app shows the exact one.
  2. iPhone: use an app that publishes an RTSP or HTTP stream and copy the address it shows. Without an app, Continuity Camera shows up below when this Mac can see it.
  3. Keep the phone on the same Wi-Fi as this PC and awake. Paste the address, press Test, then Add.
