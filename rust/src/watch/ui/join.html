Join a PC to this cluster

A PC joins only when someone runs one command on it. Nothing is installed or started on any other machine by this page.

A code lets one PC join. It works for 10 minutes and for one PC.

What the command does
  1. Downloads the worker program from this head into ~/.watch-worker and checks its sha256. If this head runs another OS it builds from the head's source instead (needs Rust).
  2. Enrolls with the pairing code and receives a worker token, stored here as a hash only.
  3. Downloads the detector models named in the head's settings (checked by sha256). Recordings are not copied: the worker reads them from the head as it goes.
  4. Runs as a worker. Press Ctrl-C on that PC to leave. Nothing else on the PC is changed.

From this PC you can also push to a machine you can reach by ssh: cw deploy user@host --head HEAD-IP

A PC is marked lost when the head has not heard from it for 15 seconds (the lease time); its work goes to another PC.

Network checklist

  • TCP 7710 on this head must be reachable from the other PCs (http, workers and this page).
  • UDP 7711 lets cw join find the head by itself when no address is given. Giving the address works without it.
  • The head listens on every interface only when started with CW_BIND=0.0.0.0. In open mode it stays on this PC otherwise.
